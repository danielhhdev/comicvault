# Crear una migración Flyway

1. Averigua el siguiente número de versión ejecutando el script de esta skill:

   ```bash
   bash .claude/skills/crear-migracion/scripts/siguiente-version.sh
   ```

   Imprime, por ejemplo, `2`. Nunca calcules el número a ojo.

2. Crea el archivo `src/main/resources/db/migration/V<n>__<descripcion_en_snake_case>.sql`
   (dos guiones bajos tras el número), por ejemplo `V2__create_series_table.sql`.

3. Escribe SQL que funcione igual en PostgreSQL y en H2 (modo PostgreSQL). Sigue
   `.claude/rules/persistence.md`: tablas en plural y `snake_case`, clave primaria
   `id BIGINT GENERATED BY DEFAULT AS IDENTITY`, columna `created_at`.

4. Una migración nunca deshace ni edita otra anterior: si hay que corregir algo ya
   commiteado, crea una versión nueva.

5. Actualiza la entidad JPA para que coincida con el esquema (`ddl-auto` es `validate`,
   así que un desajuste hace fallar el arranque) y ejecuta `mvn test`.

Entrega: nombre del archivo creado, resumen del cambio de esquema y resultado de los tests.
